## О проекте

Этот проект является модифицированной версией [Element X iOS](https://github.com/element-hq/element-x-ios)
с удаленными enterprise-компонентами и кастомным брендингом.

### Лицензионная информация
- Исходный код: AGPL-3.0
- Производная работа: AGPL-3.0
- Модификации описаны в [MODIFICATIONS.md](MODIFICATIONS.md)

### Требования AGPL-3.0:
1. Полный исходный код доступен по запросу
2. Все модификации документированы
3. Сохранены оригинальные копирайты Element
